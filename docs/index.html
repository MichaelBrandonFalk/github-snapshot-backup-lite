GithubSnapshot V1.1

A small macOS app that backs up current repository files on a weekly schedule, then lets you change the folder, schedule, retention, or repository list later.

Download App View on GitHub

Download

The app is distributed as a versioned ZIP. The primary button downloads the app directly; GitHub is available as an extra option for source code and older releases.

Download GithubSnapshot_V1.1 GitHub Repository

How To Run It

  1. Download the app ZIP.
  2. Unzip it and open `GithubSnapshot_V1.1.app`.
  3. If macOS blocks the first launch, right-click the app and choose Open.
  4. If Homebrew is missing, use the app's Install Homebrew button. It opens the official Homebrew instructions.
  5. Use the app buttons to install GitHub tools and sign in if prompted.
  6. Choose a backup folder, leave repository mode on all for set-and-forget backups, and keep Weekly enabled.
  7. Reopen the app later to change the folder, schedule, retention, or repository list.

Backup Destination

Local folder backups work now. A Google Drive for desktop folder also works now. Direct Google Drive upload is shown separately because it requires Google OAuth setup before it can be enabled safely.

First Run

A fresh Mac may need Homebrew before the app can install `git`, `gh`, and `git-lfs`. The app opens the official Homebrew page instead of running a shell installer without context.

Repository Mode

Use All discovered repositories for set-and-forget backups. Use selected mode only when you want to maintain an explicit owner/repository list.

What It Saves

Each run creates dated ZIP files containing the current files from `main`, or the repository default branch when `main` does not exist. The `.git` directory is removed before archiving.

Restore

Extract a repository ZIP, create a new GitHub repository, then initialize and push the extracted folder with standard Git commands.
