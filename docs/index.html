The macOS app is distributed as a versioned ZIP release. It requires GitHub CLI authentication and writes snapshots to any Finder-accessible folder, including Google Drive for desktop.

What It Saves

          
Each run creates dated ZIP files containing the current files from `main`, or the repository default branch when `main` does not exist. The `.git` directory is removed before archiving.
