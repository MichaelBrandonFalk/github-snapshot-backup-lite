GitHub Snapshot Backup Lite

A small macOS app that backs up current repository files on a weekly schedule, then lets you change the folder, schedule, retention, or repository list later.

The macOS app is distributed as a versioned ZIP release. It requires GitHub CLI authentication and writes snapshots to any Finder-accessible folder, including Google Drive for desktop.

How To Run It

  1. Download the latest macOS ZIP from GitHub Releases.
  2. Unzip it and open `GitHub Snapshot Backup.app`.
  3. If macOS blocks the first launch, right-click the app and choose Open.
  4. Install and sign in to GitHub CLI with `brew install gh git` and `gh auth login`.
  5. Choose a backup folder, leave repository mode on all for set-and-forget backups, and keep Weekly enabled.
  6. Reopen the app later to change the folder, schedule, retention, or repository list.

Repository Mode

Use All discovered repositories for set-and-forget backups. Use selected mode only when you want to maintain an explicit owner/repository list.

What It Saves

Each run creates dated ZIP files containing the current files from `main`, or the repository default branch when `main` does not exist. The `.git` directory is removed before archiving.

Restore

Extract a repository ZIP, create a new GitHub repository, then initialize and push the extracted folder with standard Git commands.
