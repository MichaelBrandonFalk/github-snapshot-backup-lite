GithubSnapshot V1.5.2

Weekly GitHub repository snapshots for macOS, Windows, and Linux Mint. Save locally, upload to Google Drive, or do both.

Download for macOS Download for Windows Download for Linux Mint View on GitHub

macOS: Apple Silicon. Windows: 10/11, 64-bit Intel/AMD. Linux Mint: 21/22, 64-bit Intel/AMD. Python is included.

How To Run It

macOS

Unzip the download, move GithubSnapshot_V1.5.2.app to Applications, then open it. If macOS blocks the first launch, right-click the app and choose Open. Use Install Homebrew if needed, then Install Required Tools.

Windows

Extract the entire ZIP to a permanent folder and open GithubSnapshot_V1.5.2.exe inside it. Keep the accompanying files together. Click Install Required Tools if prompted; this uses Windows Package Manager and may request administrator approval. If winget is unavailable, install App Installer from Microsoft. Reopen the app after installing tools.

Linux Mint

Open the .deb download with Package Installer and choose Install Package. The installer includes the app and installs its dependencies through the system package manager. Open GithubSnapshot from the applications menu. Internet access and your administrator password are needed during installation.

If your package installer cannot resolve dependencies, install from Terminal:

sudo apt install ./GithubSnapshot_V1.5.2_LinuxMint_amd64.deb

Save Your Settings

  1. Sign in to GitHub using the app's Sign In To GitHub button.
  2. Choose a backup destination, leave repository mode on all for set-and-forget backups, and keep Weekly enabled.
  3. The default schedule is Wednesday at 10:00 AM in your computer's local time. Choose a time when the computer is usually awake, signed in, and online.
  4. Click Save Settings. Keep the app installed in the same location; its window can be closed.
  5. Reopen the app later to change the folder, schedule, retention, or repository list.

Backup Destination

Choose Local folder, Google Drive, or both. Google Drive uses rclone for the first OAuth connection, then scheduled uploads run without another sign-in.

Missed Schedule

Pick a time when the computer is normally on and signed in. Windows Task Scheduler and Linux Mint's user timer catch up missed schedules when available. On macOS, launchd can catch up after sleep. The app also checks for missed backups when reopened.

First Run

The Windows app offers to install tools using winget. The Linux Mint installer installs required tools as dependencies. On macOS, setup uses Homebrew. Google Drive requires one browser sign-in through Connect Google Drive.

Repository Mode

Keep All Repositories checked for set-and-forget backups. Each backup scans GitHub at run time, so repositories created after settings were saved are included automatically.

What It Saves

Each run creates dated ZIP files containing the current files from `main`, or the repository default branch when `main` does not exist. The `.git` directory is removed before archiving.

Restore

Extract a repository ZIP, create a new GitHub repository, then initialize and push the extracted folder with standard Git commands.
